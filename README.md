# Solmar Bay: Hot Streets

An original open-world crime game that runs in the browser from static files — no build step, no network. You're Mara Cruz, a courier with a debt to settle in the sun-soaked coastal city of Solmar Bay: six story missions, side jobs, stealable cars, traffic and pedestrians, a wanted system with police pursuits, fists and pistol combat, and a live minimap HUD.

**Play it:** serve `game/` statically (for example `node serve.ts` from this repository) and open it in desktop Chrome. WASD to move, E to enter a car, F to interact, mouse to aim, 1/2 to switch weapon, Esc to pause. Progress saves to localStorage.

Entered in make.fun's [Make GTA 6](https://make.fun/bounty/gta6-01) bounty. `main.ts` packages `game/` and `screenshots/` into the entry dossier; everything under `game/` is plain HTML/CSS/JS drawn and sounded entirely in code.
